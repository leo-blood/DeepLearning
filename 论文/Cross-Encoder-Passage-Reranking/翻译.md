# 使用 BERT 进行段落重排序

**原题**: Passage Re-Ranking with BERT  
**作者**: Rodrigo Nogueira（纽约大学），Kyunghyun Cho（纽约大学 / Facebook AI Research）  
**发表**: arXiv 2019

---

## 摘要

近年来，在语言建模任务上预训练的神经模型（如 ELMo、OpenAI GPT、BERT）在问答和自然语言推理等多项 NLP 任务上取得了显著成果。本文描述了一种将 BERT 用于**基于查询的段落重排序**的简单实现方案。

我们的系统在 TREC-CAR 数据集上达到了当时最优水平，并在 MS MARCO 段落检索任务排行榜上位居首位，在 MRR@10 指标上比此前最优方法提升了 **27%（相对提升）**。

代码已开源：https://github.com/nyu-dl/dl4marco-bert

---

## 1. 引言

近年来信息检索领域在神经排序模型（如 DRMM、KNRM、Co-PACRR、DUET）方面取得了蓬勃发展，但直到最近才出现足够大规模的段落排序数据集（MS MARCO），使得神经排序模型能够与传统 IR 技术相竞争。

作者认为，推动机器阅读理解进步的两个核心要素同样适用于段落重排序：
1. **大规模标注数据集**（如 MS MARCO）
2. **强大的预训练模型**（如 BERT）

## 2. 方法

### 2.1 整体架构（Cross-Encoder）

本文提出的方案是一个**Cross-Encoder**架构：

```
输入格式：[CLS] 查询 [SEP] 段落文本 [SEP]
                  ↓
             BERT Large
                  ↓
          [CLS] 向量表示
                  ↓
          单层全连接层（二分类）
                  ↓
         段落相关性概率分数
```

**关键设计选择**：
- 使用 BERT 的 `[CLS]` 位置向量作为句对表示
- 查询截断至最多 **64 个 token**
- 查询 + 段落 + 分隔符的总长度截断至 **512 个 token**
- 使用 **BERT-Large** 作为基础模型

### 2.2 训练目标

使用**交叉熵损失**进行微调：

$$\mathcal{L} = -\sum_{j \in J_{pos}} \log(s_j) - \sum_{j \in J_{neg}} \log(1 - s_j)$$

其中：
- $J_{pos}$：相关段落的索引集合
- $J_{neg}$：BM25 检索的 top-1000 中不相关段落的索引集合

### 2.3 推理流程

1. BM25 从语料库中检索 top-1000 候选段落
2. 对每个候选段落独立计算相关性概率分数
3. 按概率分数重新排序，得到最终排名

## 3. 实验

### 3.1 数据集

**MS MARCO**：
- 训练集：约 4 亿条（查询、相关段落、不相关段落）三元组
- 验证集：约 6,900 个查询，每个配有 BM25 检索的 top-1000 段落
- 平均每个查询有 1 个相关段落

**TREC-CAR**：
- 基于 Wikipedia 构建的复杂问答数据集

### 3.2 训练设置

- 硬件：TPU v3-8
- Batch size：128（每批次 128 序列 × 512 token = 65,536 tokens）
- 训练轮次：100k 迭代（约 30 小时）
- 训练数据：1280 万对（100k 迭代 × 128 对），约占完整训练集的 **2%**

### 3.3 主要结果

| 方法 | MS MARCO Dev MRR@10 | MS MARCO Eval MRR@10 | TREC-CAR MAP |
|------|---------------------|---------------------|--------------|
| BM25（Lucene，无调参） | 16.7 | 16.5 | 12.3 |
| BM25（Anserini，调参） | - | - | 15.3 |
| Co-PACRR | - | - | 14.8 |
| KNRM | 21.8 | 19.8 | - |
| Conv-KNRM | 29.0 | 27.1 | - |
| IRNet（前 SOTA） | 27.8 | 28.1 | - |
| **BERT Base（本文）** | **34.7** | - | **31.0** |
| **BERT Large（本文）** | **36.5** | **35.8** | **33.5** |

### 3.4 训练数据量 vs. 性能

一个关键发现：**预训练模型只需少量标注数据即可达到良好性能**。

- BERT-Large 使用 10 万对训练数据（占 MS MARCO 训练集的 0.3%）就已超过前 SOTA（IRNet，训练于全部数据）
- 随着训练数据量增加，性能持续提升，但边际效益递减

---

## 4. 结论

1. BERT 微调后作为 Cross-Encoder 重排序器，在两个任务上均大幅超越前最优方法
2. 预训练知识显著降低了对标注数据量的依赖
3. 该方法简单有效，但**计算代价高昂**（每次查询需对每个候选段落单独前向推理）

### 局限性

- **推理速度慢**：1000 个候选段落 × 512 token 的 BERT 前向推理，延迟高
- 这一局限性直接推动了后续 ColBERT、DPR 等高效检索模型的提出
